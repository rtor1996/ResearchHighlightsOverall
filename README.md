# NIT Trichy Research Highlights — single-page dashboard

The dashboard has one GitHub Pages URL and three selectable tabs:
1. Overall Research Highlights (1996–2026)
2. Current Research Output (2025–2026)
3. OpenAlex Profile

## Update existing repository
Upload/replace `index.html`, `assets/style.css`, `assets/app.js`, and `data/` JSON files in the existing repository `https://github.com/rtor1996/ResearchHighlights`. Keep `assets/nitt-logo.png`.

The OpenAlex section is embedded in the same page as a tab. No separate GitHub Pages page is required.

## Data notes
- The year-wise SciVal file contains citation counts by year, not annual scholarly output, so the chart is labelled as a citation trend.
- Overall and 2025–2026 reports remain separate.
- OpenAlex metrics remain separate from Scopus/SciVal metrics because coverage differs.
- SciVal author records are not a verified current staff directory.
- Confirm institutional permission to publish SciVal-derived data publicly.
